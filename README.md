# 网易云音乐「音乐合伙人」每日评分系统自动化

## 写在前面

谢谢网易给我音乐合伙人，已经五年多了(截止26年）。<br>
刚开始的时候是自己认真听认真打分，很喜欢的会打5分，一般的也会打2分。
但是后来发现自己打分很难每周获得高分数，导致一个月几乎每天打分才能刚好够到320分的及格线。
其次很多时候每周小结出来一首歌4分评的人最多，但是最后平均分是3.4分导致这首歌我没有额外的分拿。
诸如此类原因我慢慢失去了认真打分的乐趣，可能认真打分的是少数或者规则还需要完善的地方。

因此开发了这个「音乐合伙人每日自动评分」的命令行工具 `wyy-rate`。

> ⚠️ 自动打分是不好的行为，平台如果检测到可能限制或取消你的合伙人资格，评分数据也会影响被评的音乐人。
> 本仓库仅作技术演示，使用与否与作者无关，后果自负。

## 功能（目前是电脑端）

- 打开评定页 → 每首**静音播放满 15 秒**（其实考虑过跳过，但是听15秒更像真人操作）
- 每首歌：总评 3 星，小项（旋律 / 演唱 / 歌词）随机 2~4 星
- 每日任务 5 首 + 加评 15 首 = 当日上限 20 首，跑完回主页核对「本期积分」

星数、首数、听歌秒数都能在调用时改

## 缺点

- 运行的时候需要网页在最前面，基本干不了自己的事（尝试了别的办法感觉都不太行）
- 索性就让他这样，空闲的时候运行这个命令就可以了

## 安装

**macOS / Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/Tousengi/wyy-rate/main/install.sh | bash
```

本来是说直接让cc或者codex帮忙安装的
但是可能由于安全协议，只能自己手动安装

## 使用

```bash
wyy-rate
```

- **第一次**会弹出一个窗口，用网易云音乐 App 扫码登录。登录状态保存在 `~/.config/wyy-rate/chrome-profile`，以后不用再扫
- 不用点页面，自动静音播放
- 终端里逐首显示进度
- 登陆过期后会自动弹出窗口重新扫码

### 参数

```
wyy-rate                      # 默认：20 首，总评 3 星，小项 2~4 星
wyy-rate song 5               # 只评 5 首
wyy-rate star 4               # 总评 4 星
wyy-rate song 10 star 4       # 组合，顺序随意
wyy-rate sub 3-5              # 小项随机区间改成 3~5 星
wyy-rate listen 20            # 每首至少听 20 秒
wyy-rate dry                  # 只打星不提交，验证页面没改版
wyy-rate mute off             # 出声（默认静音）
wyy-rate url <评定页网址>      # 换网址（也可以 appid <十六进制串>），会记住
wyy-rate login                # 只登录不评定（登录过期时用）
wyy-rate -h                   # 看全部参数
```
